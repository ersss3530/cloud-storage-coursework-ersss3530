# Отчёт по лабораторной работе № 4

## Документирование облачного проекта средствами Markdown

**Проект:** учебное HTTP API для хранения данных.
**Репозиторий:** [cloud-storage-coursework-ersss3530](https://github.com/ersss3530/cloud-storage-coursework-ersss3530).

## Назначение и архитектура

Прототип принимает HTTP-запросы и хранит записи в локальном JSON-файле. Система состоит из клиента, API-приложения, JSON-хранилища и конфигурации пути к файлу. Это учебная реализация: внешнее облачное хранилище не подключено.
